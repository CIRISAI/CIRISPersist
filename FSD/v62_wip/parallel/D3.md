## Known risks (no compiler here; pytest risks instead)

1. **I2512/I2511 depend on slice B re-targeting `cirisnode_put_goal_json` onto `sign_row`.** If the goal producer still writes a JSON row, A serves no `row` statement and the `gid in rows` asserts fail. That is a true red for B's exit criterion, but the builder should know where it comes from. Also unverified: that B's gates admit a peer's self-scale goal from a `user` key with no further context.
2. **`register_self_federation_key`'s new signature** comes from D1's note on cut B. If the final cut B keeps any positional argument, the 16 adjusted calls and I2510's `TypeError` check change with it.
3. **`from conftest import …`** relies on pytest's default `prepend` import mode. If CI runs pytest with `--import-mode=importlib`, those imports fail; then move the helpers to a `tests/python/_edition2.py` module.

Other risks:
- I2513 assumes positions sort by `(admitted_us, statement_id hex)` in serving order. Per the CHANGELOG, `admitted_us` is "after the last one handed out", so it rises strictly; the hex tie-break never fires.
