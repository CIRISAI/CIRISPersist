## The fixture

Module `crate::federation::edition2::fixture_trust_root`, gated `#[cfg(any(test, feature = "test-anchor"))]`. Integration tests reach it as `ciris_persist::federation::edition2::fixture_trust_root`.

```rust
use ciris_crypto::composite::CompositeSigningKey;
use crate::federation::edition2::names::RowId;

/// The root's E0 seed: the root's identity-ref is `e2::kid(ROOT_SEED)`.
pub const ROOT_SEED: &str = "w1-rooted-trust-root";

#[derive(Clone, Debug)]
pub struct RootedTrustRoot {
    /// The root's identity-ref (= the community_key_id = `e2::kid(ROOT_SEED)`).
    pub root: String,
    /// The founders' identity-refs, in the order given (holders of the genesis bundle in force).
    pub founders: Vec<String>,
    /// Their holder seeds, same order.
    pub founder_seeds: Vec<u8>,
    /// The `consensus_protocol` the root was founded at.
    pub protocol: String,
    /// The founding `group:roster` version's row id (every founder voiced it).
    pub birth: RowId,
    /// The root's `trust:charter:v1` self-edge `delegates_to(root → root)`, signed by the root's key.
    pub charter: RowId,
    /// THIS node's `trust:accepts:v1` edge `delegates_to(node → root)`, naming the root's head.
    pub acceptance: RowId,
}

/// Stand up a ROOTED trust root on `dir`:
/// 1. installs `fixture_genesis::bundle_v2()` when no genesis is held (idempotent);
/// 2. registers the root's key (`e2::put_key(dir, ROOT_SEED, &["user"])`);
/// 3. founds an `infrastructure` community at `root`: every founder is a FOUNDER
///    and voices the founding `group:roster` (counted against a strict majority of
///    the bundle's holders, W1's door);
/// 4. puts the root's charter self-edge (`trust:charter:v1`, scope `infra:serve` +
///    `infra:attest`, a well-formed `pre_rotation_commitment`);
/// 5. puts THIS node's acceptance edge (`trust:accepts:v1`, `attached_head_digest` =
///    the held head) signed by the node's key.
///
/// `founders`: holder SEEDS of the bundle in force (`bundle_v2()`: 1, 2, 3).
/// `protocol`: `quorum:M/N` (an `infrastructure` community; N = founders.len() >= M + 1).
///
/// PRECONDITION: `dir.node_key_id()` is a kid E0 minted in this process, e.g.
///   `let node = e2::put_key(&backend, "my-node", &["node"]).await; backend.set_node_key_id(node);`
/// (`set_node_key_id` is the sqlite / postgres backends' inherent setter).
///
/// # Panics
/// A refusal at any step, or no node key (it is a fixture).
pub async fn rooted_trust_root<D: FederationDirectory + ?Sized>(dir: &D, founders: &[u8], protocol: &str) -> RootedTrustRoot;

/// The same, returning the first refusal.
pub async fn try_rooted_trust_root<D: FederationDirectory + ?Sized>(dir: &D, founders: &[u8], protocol: &str)
    -> Result<RootedTrustRoot, Error>;

impl RootedTrustRoot {
    /// Founder i's signing key (`fixture_genesis::test_key(founder_seeds[i])`); it signs as `founders[i]`,
    /// e.g. `group_fixtures::sign_group_payload(&r.founder_key(i), &r.root, typed::TAKEDOWN_PREFIX, &p)`.
    pub fn founder_key(&self, i: usize) -> CompositeSigningKey;
}
```

## Production (what the fixture's root satisfies)

```rust
// canonical_community
/// The CHAIN verdict (was stored_standing_at's body): the record's chain from its
/// birth, every founder counting. The doors (admission, chain apply, supersede)
/// read this one.
pub async fn chain_standing_at<F>(dir: &F, community_key_id: &str, now: DateTime<Utc>) -> Result<StoredStanding, Error>;
/// The READ verdict. For an edition-2 trust root (its versions have edition-2 voices):
/// the chain verdict AND THIS node's own T3 chain (CC 3.2 T3, CC 4.4.3.34: the node
/// is its own seed): a live `trust:accepts:v1` edge from the node (or its owner)
/// to the root, and the root's live `trust:charter:v1` self-edge with a well-formed
/// pre-rotation commitment. Missing either: `NotRooted { reason }`.
/// An earlier-form chain is read only while the earlier-form doors are open.
pub async fn stored_standing_at<F>(..);          // unchanged signature
pub async fn stored_standing<F>(..);             // unchanged signature

// trust_root
pub struct OwnChain { pub accepted: bool, pub chartered: bool }
/// THIS node's T3 chain to `root` (no community arm, no recursion into standing).
pub async fn own_chain_to<F>(dir: &F, root: &str, now: DateTime<Utc>) -> Result<OwnChain, Error>;
```

**Consequence for T2 / E7:** `StoredStanding::Rooted` now needs the node key to be set and to accept the root. A backend without `node_key_id` reads every edition-2 root as `NotRooted` (CC: `None` means it cannot verify).

## v1.3: idempotent; a conferral helper; the readers (W1b update 3)

- **`rooted_trust_root` is IDEMPOTENT per directory** (same founders and protocol, same bundle in force). Every statement is stated at the bundle's newest tip + 60 s (founded_at + 30 s), so a second call re-puts identical payloads (no-ops) and returns the SAME `birth`/`charter`/`acceptance` row ids. Two directories standing it up independently hold the same row ids too. Call it as often as you like.
- New helper:
  ```rust
  /// The root's trust:confers:v1 grant delegates_to(root → subject) with `scope`, signed by the root.
  /// Verify's `confers` rule asks for the subject's second voice: put `e2::voice_of(&st, subject_seed)` after it.
  pub fn confers_statement(r: &RootedTrustRoot, subject: &str, scope: &[&str], asserted_at_ms: u64) -> Vec<u8>;
  ```
- **Readers on edition 2:**
  - `canonical_community::rooted_community_family(dir, id)` returns `Some(id)` itself for a ROOTED edition-2 root (its chain verdict), so `trust_root_valid(user, root)` takes the community arm with every leg read at the root's own id: the user's acceptance edge, and the root's self-charter with its recovery commitment.
  - `capability_roots_to_trusted_root` reaches it through the delegation plane (`trust:confers:v1`).
  - Its AccordCoScrub (ceremony-plane) fallback is read only while the earlier-form doors are open.
  - The earlier accord-family arm is reached only through `stored_standing`, hence only while the earlier-form doors are open.

## v1.4: the held root is returned; `put_conferral` (W1b update 4)

- **A second `rooted_trust_root` call RETURNS the held root.** When the root, its birth voices, its charter and THIS node's acceptance are already held, nothing is put. A root held at `ROOT_SEED` that was founded with other founders or another protocol is refused ("would fork").
  - With a different node key, the new node's acceptance edge is put; nothing else is.
- **New:**
  ```rust
  /// The root confers `scope` on `subject_seed`'s key (registered `user` first): the root's
  /// trust:confers:v1 grant, then the subject's own second voice (Verify's `delegate: sub`).
  /// Idempotent (stated at the bundle's newest tip + 90 s). Returns the grant's row id.
  pub async fn put_conferral<D: FederationDirectory + ?Sized>(dir: &D, r: &RootedTrustRoot,
      subject_seed: &str, scope: &[&str]) -> Result<RowId, Error>;
  ```
  To make an infrastructure room reached by conferral, call `put_conferral(d, &r, room_seed, &["infra:serve"])` with the room's E0 seed; the room's key co-signs.
