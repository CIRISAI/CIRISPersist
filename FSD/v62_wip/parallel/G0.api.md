# G0 API: the held/concluded fold (CC 2.7.3)

**Status: v1 (2026-11-18). Nothing is built; every signature is BELIEVED, read-checked against syn0 + X2.patch (13:38) + V1-onX2.patch (13:37) + W1b.patch (13:36).** Invariants I3550–I3599.

Module: `crate::federation::edition2::fold` (new file `src/federation/edition2/fold.rs`).

## 0. The rule this implements

CC 2.7.3: "A row waits for what it names. It is never refused for what another row says: a check that reads another row concludes nothing." Lead's ruling (CC 2.7): the DOOR refuses only on (1) the statement's own bytes and (2) the signer's own key plane. **Everything else is the FOLD**: the row is HELD (its statement kept in `ceg_statements`) and its typed projection is CONCLUDED only while its fold conditions hold.

- **Held** = in `ceg_statements`. Every door-valid row is held.
- **Concluded** = its typed row is in its typed table (`federation_attestations`, the group tables, ...). Readers read the typed tables and see ONLY the concluded set. Nothing about readers changes.
- **Held, concluding nothing** = held, no typed row, and a row in `ceg_fold_held` naming the REASON (a token) and a detail.
- When any input a fold read changes (a row concludes, un-concludes, or a new voice lands), every row whose fold READ that input is re-folded, in a deterministic worklist, until nothing changes. The result is a function of the held set, not of arrival order.

## 1. What a gate does (the conversion recipe)

A gate is an `async fn check_*(dir, row) -> Result<(), Error>` on the attestation path (`attestation_admit::plan_put_attestation`). To convert it from "refuse" to "hold":

```rust
use crate::federation::edition2::fold::{self, reason, Dep};

// 1. Declare every input you read beyond the row itself (no-op outside a fold attempt).
//    The shared readers already do this for you (§4); add it only for a direct read.
fold::reads(Dep::key(&row.attested_key_id));

// 2. On the failing branch, wrap the refusal you already return:
return Err(fold::hold(reason::OWNER_UNSEATED, Error::InvalidArgument(..)));
```

- `fold::hold(reason, err) -> Error` marks the CURRENT fold attempt held with `reason` (and `err.to_string()` as the detail) and returns `err` unchanged. **Outside an attempt** (the earlier-form JSON door, a read-time fold, a replay) it is a plain refusal: behaviour there does not change.
- A gate never matches on error text; the mark is structural.
- A refusal NOT wrapped in `hold` stays a refusal (nothing kept) — that is correct ONLY for the statement's own bytes and the signer's own key plane. Every other refusal is to be converted.
- Pick a reason token from `fold::reason` (§2) or append one there (append-only, never reorder).
- Do NOT call `hold` for a door-class check (bytes, schema, family static check, time members, signature, the signer's key record / rotation / occurrence / seat / identity-set exclusion / reserved-family emitter class).

`voices::note_short()` (V1b) is now `fold::note(reason::COUNT_SHORT)`; every V1b shortfall gate is therefore already converted, with reason `count_short`.

## 2. Types

```rust
pub mod reason {
    pub const COUNT_SHORT: &str = "count_short";           // voices short of the count (T1/V1b/O1/W1 Pending)
    pub const OWNER_UNSEATED: &str = "owner_unseated";     // owner_of(subject) is not the signer (G0 exemplar)
    pub const STEWARD_UNPROVEN: &str = "steward_unproven"; // the steward-binding gate's age/granter reads (G0 exemplar)
    pub const AMENDMENT_DIGEST_MISMATCH: &str = "amendment_digest_mismatch"; // reserved for P2's conversion
    pub const REFOLD_REFUSED: &str = "refold_refused";     // a re-fold met a refusal no gate marked held
    pub const REFOLDING: &str = "refolding";               // transient: a concluded row is being re-checked
    /// Every token, APPENDED in this order (adopters key on the text).
    pub const ALL: &[&str] = &[COUNT_SHORT, OWNER_UNSEATED, STEWARD_UNPROVEN,
        AMENDMENT_DIGEST_MISMATCH, REFOLD_REFUSED, REFOLDING];
}

/// One input a fold read. Its key is the text stored in `ceg_fold_reads.read_key`.
#[derive(Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum Dep {
    /// A row by id (its voices, a withdrawal of it, an approval naming it): "row:<hex>".
    Row(RowId),
    /// Any row ABOUT or BY this key / identity-ref (bindings, roster seats, age witnesses): "key:<id>".
    Key(String),
    /// The coarse fallback: any row of this family: "family:<family>".
    Family(String),
}
impl Dep {
    pub fn key(id: &str) -> Self;            // Dep::Key(id.to_owned())
    pub fn read_key(&self) -> String;        // "row:<hex>" | "key:<id>" | "family:<f>"
}

/// Why a held row concludes nothing.
#[derive(Clone, Debug, PartialEq, Eq, serde::Serialize)]
pub struct HeldReason {
    pub row_id: RowId,         // serialised as hex
    pub family: String,
    pub tier: String,          // the tier the row concludes at
    pub reason: String,        // a `reason::*` token
    pub detail: String,        // the refusal the gate would have raised, as text
    pub since_us: i64,         // THIS node's clock when it was first held for this reason (node-local)
}

/// What a fold evaluation recorded for one row (the storage unit).
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct FoldRecord {
    pub row_id: RowId,
    pub family: String,
    pub tier: String,
    /// `None` = concluded; `Some((reason, detail))` = held, concluding nothing.
    pub held: Option<(String, String)>,
    /// Every input the evaluation read (`Dep::read_key`), always including "row:<own id>".
    pub reads: std::collections::BTreeSet<String>,
}

/// What one re-fold pass changed.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct RefoldReport {
    pub concluded: Vec<RowId>,    // held -> concluded
    pub unconcluded: Vec<RowId>,  // concluded -> held
    pub still_held: Vec<RowId>,   // re-folded, still held (reason may have changed)
    pub steps: usize,
}
```

## 3. Functions

```rust
// ── for gates (task-local, no I/O) ─────────────────────────────────────
pub fn reads(dep: Dep);                                  // no-op outside an attempt
pub fn hold(reason: &'static str, err: Error) -> Error;  // marks + returns err
pub(crate) fn note(reason: &'static str);                // mark without an error (V1b's note_short)
pub fn in_attempt() -> bool;

// ── the reason API (readers, adopters) ─────────────────────────────────
/// Why `row_id` concludes nothing; `None` when it is concluded or not held.
pub async fn why_held<F: FederationDirectory + ?Sized>(dir: &F, row_id: &RowId) -> Result<Option<HeldReason>, Error>;
/// The held rows that conclude nothing, in row-id order after `after`, at most `limit` (clamped to 1000).
pub async fn held_rows<F: FederationDirectory + ?Sized>(dir: &F, after: Option<&RowId>, limit: u32) -> Result<Vec<HeldReason>, Error>;

// ── the re-fold hook ───────────────────────────────────────────────────
/// The read keys a statement touches: row:<its id>, row:<every id it names>,
/// key:<iss|sub|author|kid hex>, key:<attesting|attested|subject ids of its projection>, family:<family>.
pub fn touches(admitted: &AdmittedRow) -> BTreeSet<String>;
/// Re-fold every row that read any of `touched`, then every row THOSE changes touch, until
/// nothing changes (worklist in row-id order; bounded by MAX_REFOLD_STEPS = 4096, then a
/// `tracing::warn!` and stop — the remainder re-folds on the next touch or `refold_all`).
pub async fn refold_touched<F: FederationDirectory + ?Sized>(dir: &F, touched: BTreeSet<String>) -> Result<RefoldReport, Error>;
/// Re-fold exactly these rows (and cascade).
pub async fn refold_rows<F: FederationDirectory + ?Sized>(dir: &F, rows: BTreeSet<RowId>) -> Result<RefoldReport, Error>;
/// Re-fold every held row (a repair sweep: after a crash mid-refold, or a rule change).
pub async fn refold_all<F: FederationDirectory + ?Sized>(dir: &F) -> Result<RefoldReport, Error>;

// ── the door's tail (called by ingest; conversion agents don't call these) ──
/// Run `fut` (the attestation gates) as a fold attempt for `row_id`, with `offered` counted as a
/// voice of it. Returns the future's output and what the attempt recorded.
pub(crate) async fn attempt<T>(row_id: RowId, offered: Option<voices::Voice>,
    fut: impl Future<Output = T>) -> (T, Option<(String, String)>, BTreeSet<String>);
/// The offered voice of the current attempt, if it is for `row_id` (voices::voices_of_row reads it).
pub(crate) fn offered_voice(row_id: &RowId) -> Option<voices::Voice>;
/// After `put_statement` stored a statement: record a hold for a plane that answered `Pending`
/// without an attempt (T1, O1, W1: reason `count_short`), clear it when that row concludes, and
/// run `refold_touched(touches(admitted) ∪ the touches of every held attestation it names)`.
pub(crate) async fn after_statement<F: FederationDirectory + ?Sized>(dir: &F, admitted: &AdmittedRow,
    tier: &str, outcome: &StatementOutcome) -> Result<(), Error>;
```

`StatementOutcome::Pending { row_id, new }` is unchanged in shape: it IS the held outcome ("kept, concludes nothing"); its reason is `why_held(row_id)`.

## 4. Shared readers that declare their reads (so callers need not)

| reader | declares |
|---|---|
| `admission::owner_of(dir, node)`, `admission::kernel_owner_selves(dir, node, _)` | `Dep::Key(node)` |
| `admission::steward_binding_paths_of(dir, k)` (and so `steward_bindings_of`, `is_steward_bound`) | `Dep::Key(k)` |
| `age::age_band(dir, k)` | `Dep::Key(k)` |
| `voices::voices_of_row(dir, row_id)` (and every counter over it) | `Dep::Row(row_id)` |

A conversion agent whose gate reads through other helpers adds `fold::reads(..)` at the helper (preferred) or the gate.

## 5. Storage (V300, both dialects; V300 is unshipped)

```sql
CREATE TABLE ceg_fold_held (row_id BLOB PK (32), family TEXT, tier TEXT, reason TEXT, detail TEXT, since_us INTEGER);
CREATE TABLE ceg_fold_reads (read_key TEXT, row_id BLOB (32), PRIMARY KEY (read_key, row_id));
CREATE INDEX ceg_fold_reads_row ON ceg_fold_reads (row_id);
```
(postgres: `cirislens.`, `bytea`, `bigint`.) Both join `store::edition_baseline::EDITION_TWO_ADDITIONS`.

`FederationDirectory` gains (defaults: readers empty, writers `Unsupported`; sqlite + postgres implement all six):

```rust
async fn put_fold_record(&self, rec: &edition2::fold::FoldRecord) -> Result<(), Error>;            // one tx: reads replaced; held upserted (since_us kept while the reason is unchanged) or deleted

async fn fold_held_page(&self, after: Option<&edition2::names::RowId>, limit: u32) -> Result<Vec<edition2::fold::HeldReason>, Error>;

```

## 6. Adopter surface

- Rust: `Engine::edition2_held_reason(row_id: [u8; 32]) -> Result<Option<HeldReason>, Error>` and `Engine::edition2_held_rows(after: Option<[u8; 32]>, limit: u32) -> Result<Vec<HeldReason>, Error>`.
- Python (`ciris_persist.pyi`): `edition2_held_reason(row_id: str) -> str | None` (JSON of `HeldReason`, `row_id` hex) and `edition2_held_rows(after: str | None = None, limit: int = 1000) -> str` (a JSON array). `put_edition2_statement`'s `"pending"` plane is the held outcome; ask `edition2_held_reason` why.
- Capsule: the six trait methods are I1162-allowlisted (the fold runs in the process that owns the store; the proxy routes `put_edition2_statement`, whose tail runs the fold).
