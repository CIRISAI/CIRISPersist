### New edition-2 helpers (after `exercise_trust_root`)
W1b's `rooted_trust_root` stands up one root per directory (`ROOT_SEED`). The bodies also need roots this node has not accepted, foundings short of the count, a second root to let lapse, and a charter whose row id is known before it lands. The helpers use the same doors and shapes as `fixture_trust_root.rs` (read-checked):
- `e2_now_ms`, `e2_payload` (deterministic CDE map), `e2_text`
- `e2_trust_edge(signer_seed, iss, sub, members)`: a `delegates_to` at `trust:{job}:{version}` (`typed::TRUST_PREFIX`)
- `struct E2Root { seed, root, founders, birth, charter }`
- `e2_root_community(root, members, protocol, founded_at)`: the infrastructure record (W1b's shape)
- `ensure_e2_genesis`: installs `bundle_v2` when none is held
- `found_e2_root(dir, root_seed, members, protocol, signers, at_ms) -> (root, birth, StatementOutcome)`
- `e2_charter_statement(root_seed, root, at_ms)`: pure, so its row id is known first
- `stand_up_e2_root(dir, seed)` / `stand_up_e2_root_at(dir, seed, at)`: the **twin of `establish_trust_root_side`**: founded by all three bundle holders at `quorum:2/3`, plus its charter. Nobody accepts it.
- `e2_acceptance_statement(granter, root, head, at, valid_until)`, `accept_e2_root_at`, `accept_e2_root`: `trust:accepts:v1`, naming the held head when the root is a held community
- `confer_e2(dir, signer_seed, subject_seed, scope)`: **the twin of `grant_scope`**: `trust:confers:v1` plus the delegate's second voice (Verify's `delegate: sub`)
- `withdraw_e2(dir, granter, sub, edge)`: T2's `trust_withdraws_statement`
- `e2_node(dir, tag)`: the node key, or a panic naming the runner precondition
- `establish_e2_trust_root(dir, root_seed, subject_seed, scope) -> Result<E2Root>`: **the twin of `establish_trust_root`**. It keeps #536's self-enforcing postcondition: `Err` unless `capability_roots_to_trusted_root(node, subject, scope)` roots at the new root (I3346).
- `seed_chartered_e2_root(dir, root_seed, granter) -> Result<E2Root>`: **the twin of `seed_chartered_family_root`**.
- `e2_trust_edge_by_key(key, iss, subject, scope)`: a holder's `trust:confers:v1`, signed by the holder's bundle-placed key.
- `put_transport_node(dir, seed)` (private): an E0 key with identity set `{infra:transport, node}`. This replaces `register_transport_node`, which is deleted (its only callers were these bodies).

**The earlier helpers are kept unchanged:** `establish_trust_root(_side)`, `seed_chartered_family_root(_with_scrubs)`, `grant_scope`, `emit_trust_edge`, `withdraw_attestation`, `seed_test_family*`, `charter_family_and_version`, `signed_trust_attestation_signed_by`. Their callers are other agents' WRAPPED earlier-form tests (rc7_accord, kernel_adapter, android_custody, trust_root_hardware, bounded_reads, lineage_head, canonical_community_invariants, observe/tests). Re-pointing them in place would break those callers at runtime (they run under the earlier form), and the callers also assert on ids the edition-2 root does not have (`fam`, `"{fam}-charter"`). Each caller flips to the twin when it is rewritten; the earlier helpers go with the last caller (F0/CP2). **There is no twin for `seed_chartered_family_root_with_scrubs`**: the holder-hardware leg on an edition-2 root waits for the ruling in finding 2 below.
