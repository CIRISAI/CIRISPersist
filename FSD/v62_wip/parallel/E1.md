## 1. The mechanism (helpers added to `mod tests`)

All of these sit on E0's `fixture_switch`, imported as `use crate::federation::edition2::fixture_switch as e2;` in both `tests` and `accord_tests`. They do not duplicate E0's helpers; they put E0's helpers together in the shapes this file needs.

### Key registration
- 176 `backend.put_public_key(SignedKeyRecord { record: X }).await.unwrap()` chains became `e2::put_key_row(&backend, &X).await`. This was done by script; the receiver is adjusted where `backend` is already a reference (`backend`) or an `Arc` (`&*backend`).
- `fed_key(k, _, _)` now returns `e2::key_row(k, &[PRIMITIVE])`.
- `fed_key_with_identity_type(k, _, _, ity)` now returns `e2::key_row(k, &ity.split(','))`, so a folded `join_set` becomes the record's set.
- `fed_key_derived(alias)` is `fed_key(alias, ..)`: the derived id IS `kid(alias)`.
- `ensure_key` and the `let _ = be.put_public_key(..)` calls inside `put_score` / `put_composer` go through `e2::put_key_row` too.

### Rows: `e2_row(row)`, `pub(super)`, also used by `accord_tests`
- **The general case.** An earlier-shaped row becomes `e2::row_of(&row, row.attesting_key_id)`. A row that already carries `ceg_statement` (a flipped builder's) passes through unchanged. Every `SignedAttestation { attestation: X }` in the tests (127 sites) now wraps `X` in `e2_row(..)`.
- **Type-keyed rows.** A type outside `attestation_type::ALL` (for example `age_assurance:provider:adult:v1` used as the type) becomes `scores` with `dimension = <type>` (plus `score` / `confidence` when absent). This is the mapping E0's `typed_family_row` uses.
- **Composers.** A `withdraws` / `recants` / `supersedes` row with no `dimension`:
  - its `references_attestation_id` is translated first: a test-chosen target id goes to the target's row id;
  - it is signed with `e2::statement_of_family(.., <the target's family>)`;
  - the target's family comes from a thread-local map that `e2_row` fills for every row it maps. When the target is unknown, the default `fed_attestation` row's family is used.
- **Chosen ids.** A thread-local map keeps chosen id ↔ row id:
  - `e2_rid_of(chosen)` gives the row id;
  - `e2_chosen_of(rid)` gives the chosen id back, so listings can be asserted in the test's own names.
  - All `get_attestation("lit")` calls became `get_attestation(&e2_rid_of("lit"))`.
  - `.map(|a| a.attestation_id)` listings became `.map(|a| e2_chosen_of(&a.attestation_id))`.
  - The mapping is sound because a row id is a pure function of type, family, sub, author and payload (`names::RowId::of_row`, read-checked), and the payload carries the envelope's `"id"`.

### Refusals: `refusal_of(&backend, row) -> Error`
- This is the error at whichever door refuses first: the edition-2 door (`e2::try_row_of`), or `put_attestation`'s gates behind it.
- All 13 `let err = backend.put_attestation(SignedAttestation{attestation: e2_row(x)}).await.unwrap_err()` sites route through it.
- The assertions on specific typed errors were kept (see risk R3).

### Other helpers
- **`resign_fed`** no longer re-signs. Signing happens at `e2_row`. It keeps only the `delegates_to` term (`with_test_term`).
- **`put_owner_binding(dir, owner, node)`** puts `ts::owner_binding_attestation` with `e2::put_signed`, then the node's voice (`e2::voice_of`) with `e2::put_statement`, as E0.api.md §6 prescribes.
- **`put_key_revocation(backend, signer, subject) -> String`** puts `e2::key_revocation` through `e2::put_statement` and returns the `KeyPlane` row id hex. That id is the projected `revocation_id`.
- **Raw-SQL key and subject literals** (`'occ'`, `'k1'`, `'k9'`, `'subj'`, `'[\"subj\"]'`, `'registry-steward'`) are now bound parameters carrying `e2::kid(..)`. The raw-insert read-filter tests still hit the `attesting_key_id` FK this way.
- **`local_input` / `local_rows`** map the attester through `e2::kid_or_keep`.
- **`gate_for`** scores each key under both its seed and `kid(seed)`.
- **`scores_base_ts`** is now today 00:00 UTC minus 30 days (it was 2023-11-14). An `agent` record is live from today minus 180 days for at most 365 days, and a row is judged at its own `asserted_at` (`liveness.rs:285`, read-checked). The base is calendar-relative, so it does not decay on a date.
- **`register_hybrid_producer` / `hybrid_witness_signer`** (STH streams) now return `Box<e2::signing_key(key_id)>` and register `fed_key(key_id)`. The `put_stream_sth(.., "producer-key")` producer ids and the cosign `witness_id`s became `&e2::kid(..)`.
