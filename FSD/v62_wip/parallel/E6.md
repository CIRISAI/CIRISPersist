## Conventions (grep-able)

- `use crate::federation::edition2::fixture_switch as e2;` and `crate::federation::edition2::fixture_genesis`.
- A key that signs a flipped row is put with `e2::put_key(dir, seed, &[identity_type])`; every comparison, fold argument, envelope member and occurrence names it by KID (`e2::kid(seed)` / the value `put_key` returns / `e2::kid_or_keep`). The seed is kept only where a fixture signs.
- A one-off earlier-shaped row that is mutated before signing is built under `e2::with_earlier_form(|| builder(..))` and signed once with `e2::row_of(&row, seed)`: a flipped builder's mapped row carries its instants in the envelope, so a column changed afterwards is lost by `statement_of`. Where a fixture moves `asserted_at` it also restamps the envelope member.
- A stored id is always read off the row that was put (`row.attestation_id`), never a literal: an edition-2 id is computed. Fixtures whose content was identical per call got a distinguishing member/millisecond.
- Unregistered fixture dimensions moved to registered families (E0: the door refuses an unregistered dimension). Generic `scores` fixtures use `capacity:integrity` or `integrity:<token>`; both are registered in Verify's `data/cc/family_authorship.json` (v23.3.0, read-checked) and persist's `namespace/registry.rs` (read-checked).
- Genesis: `seed_genesis_accord_holders` + `seed_family_and_canonical`, `canonical_genesis_bundle().serve_nodes[0]`, co-scrub canonical conferral -> `fixture_genesis::install_v2(dir)` + `bundle_v2().serve_node_identity_ref(0)`.
- Tests that must stay in the earlier form until a typed edition-2 plane exists wrap their SYNC builder calls in `e2::with_earlier_form` (helper script: `scratchpad/E6/bin/wrap_ef.py`, not shipped).
