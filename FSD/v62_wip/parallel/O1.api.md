# O1 API: shared `identity:occurrence` bind fixtures, and the agent owner lookup

Status: v3 (2026-11-18). v3 adds "Node-bearing in edition 2" (for E7). v2 added the transaction-level occurrence write for C1's genesis import (below), and `OccurrenceBind.statements`. Nothing is built: every line is BELIEVED. If a signature changes, this line says so.

## Fixtures (`#[cfg(any(test, feature = "test-anchor"))]`)

These live in the module `crate::federation::edition2::fixture_occurrence`. They are re-exported from E0's `fixture_switch`, so call them as `e2::…`:

```rust
use crate::federation::edition2::fixture_switch as e2;

pub struct BindOptions {
    pub asserted_at_ms: u64,                    // default: now (E0's `ms(now)`)
    pub valid_until_ms: Option<u64>,            // default: None (indefinite)
    pub extra: Vec<(&'static str, Value)>,      // more payload members: transport_destination,
                                                // encryption_pubkeys, transit_xwing_pubkey, ... (CBOR)
}
impl Default for BindOptions;

/// The voices of one bind, in door order:
/// [the occurrence key's own statement, the author's statement].
/// The self pair (author == identity == occurrence) returns ONE statement.
pub fn occurrence_bind_voices(author: &str, identity: &str, occurrence: &str,
                              device_class: &str, opts: &BindOptions) -> Vec<Vec<u8>>;

/// Each voice through ingest::put_statement, in order. Returns the last outcome
/// (StatementOutcome::Row when the bind landed).
pub async fn put_bind<D: FederationDirectory + ?Sized>(dir: &D, author: &str, identity: &str,
    occurrence: &str, device_class: &str, opts: &BindOptions) -> Result<StatementOutcome, Error>;

/// An agent's owner binding, held: delegates_to(owner → agent) at
/// `ownership:responsible_party:agent:v1`, the owner's statement plus the agent's own.
/// Panics on a refusal.
pub async fn put_agent_owner_binding<D: FederationDirectory + ?Sized>(dir: &D, owner: &str,
    agent: &str, asserted_at_ms: u64);
```

- Every key argument is an E0 seed, or an identity-ref the fixtures derived. They go through `e2::kid` / `e2::signing_key`.
- **A person's device:** `put_bind(d, "alice", "alice", "alice-phone", "phone", &BindOptions::default())`. The author is the identity. With one roster key, the bind lands.
- **An agent:** first `put_agent_owner_binding(d, "alice", "agent-a", t)`, then `put_bind(d, "alice", "agent-a", "agent-a-key", "agent", &opts)`. The owner authors the bind, and the identity is the agent's.
- **Keys must be live first:** `e2::put_key(d, seed, &["user"])`. An agent identity or agent key needs `&["agent"]`, whose default record window starts 180 days back, so it covers "now".
- **Refused shapes** (useful in negative witnesses):
  - `occurrence_binds_machine_to_person`: an agent key under a user identity, or `"agent"` under a user identity;
  - `agent_occurrence_unowned`: no owner binding;
  - `agent_occurrence_not_owner_authored`: author = the agent itself;
  - `valid_until_not_after_asserted_at`;
  - retryable `federation_attester_key_unknown`: the author's voice offered alone.

## Production

- `crate::federation::admission::agent_owner_of<F: FederationDirectory + ?Sized>(dir: &F, agent: &str, at_ms: u64) -> Result<Option<String>, Error>`
  - The agent-side analogue of `owner_of`, read from the edition-2 statement store.
  - More than one owner is `Error::AmbiguousNodeOwner`.
- `crate::federation::edition2::occurrence::edition2_signature_placeholder() -> TransportBindingSignature`
  - What the signed occurrence listing reports as `signature` for an edition-2 bind: an empty Ed25519 half and no ML-DSA half.
  - The bind's authority is `signed_envelope["ceg_statement"]` (the author's statement, hex). `signed_envelope["ceg_statements"]` holds every voice.
- `crate::federation::edition2::occurrence::OccurrenceBind` gained `statements: Vec<Vec<u8>>`.

## The transaction-level occurrence write (v2; for C1's atomic genesis import)

C1 proposed these signatures and O1 adopted them unchanged:

```rust
// crate::federation::occurrence_admit
pub(crate) type ProjectedRoute = crate::federation::TransportDestination;   // Clone
pub(crate) fn plan_edition2_occurrence(bind: OccurrenceBind)
    -> Result<(PlannedOccurrence, Option<ProjectedRoute>), Error>;           // pure, no I/O
pub(crate) async fn after_edition2_occurrence<D: FederationDirectory + ?Sized>(
    dir: &D, applied: bool, identity: &str, occurrence: &str, route: Option<&ProjectedRoute>,
) -> Result<(), Error>;   // AFTER the caller's commit: route projection; re-wrap iff identity != occurrence

// crate::store::sqlite (conn class HelperWrite: call only from a Write body)
pub(crate) fn sqlite_store_edition2_occurrence(tx: &rusqlite::Connection, planned: &PlannedOccurrence)
    -> Result<bool, crate::federation::Error>;   // upsert + history; no tx, no commit

// crate::store::postgres
impl PostgresBackend {
    pub(crate) async fn pg_store_edition2_occurrence<C: deadpool_postgres::GenericClient + Sync>(
        &self, tx: &C, planned: &PlannedOccurrence) -> Result<bool, crate::federation::Error>;
}
```

- `OccurrenceBind { occurrence, author_key_id, row_id, statements }`. `occurrence` comes from `occurrence::read_payload(&AdmittedRow)`, which is pure.
- The route projection is not transaction-level, because it goes through `put_transport_destination`. Run `after_edition2_occurrence` after the commit.

## Node-bearing in edition 2 (v3; for E7)

`crate::federation::is_node_bearing_key(dir, key)`, `is_node_bearing_key_at` and `node_bearing_of` read the edition-2 facts. A key is node-bearing in exactly two ways.

1. **Its own `key:record` carries `node`.** The `federation_keys` projection's `identity_type` comes from the record, so nothing more is needed.
   - Fixture: `e2::put_key(d, "n1", &["node"])`.
   - Or, from a `door_invariants` fixture: `key_record(&k, &["node"], t - 1 day, Some(t + 200 days))`.
2. **It is an occurrence of a `node` identity, by an edition-2 bind it agreed to.**
   - The bind lands under the node's identity, with `author` = the node identity (CC 3.3.6.2: "authored and signed by the identity it binds"; a NODE does not take an owner as author, only an agent identity does).
   - The key's own statement is its agreement.
   - The interval starts at that agreement and ends at `valid_until` or a revocation.
   - The key must NOT be a person's key: binding a `user` / `accord_holder` key under a node identity is refused `occurrence_binds_machine_to_person` (the identity-set exclusion, both directions).
   - Fixture:
     ```rust
     e2::put_key(d, "n1", &["node"]).await;
     e2::put_key(d, "svc", &["primitive"]).await;      // any non-person, non-node type
     e2::put_bind(d, "n1", "n1", "svc", "service", &BindOptions::default()).await?;  // author n1, identity n1
     // is_node_bearing_key(d, &e2::kid("svc")) == true
     ```

- **Not node-bearing:** a `user` key, which can never be bound under a node identity.
- **The lead's suggested shape** (a `server` occurrence of the node under the node's own identity, with the owner as author) is not one the door admits. A node's bind is authored by the node identity, and only an agent identity's bind is owner-authored. The node's own record already makes it node-bearing (1).
- **The earlier form:** `agreed_from_in`, an earlier-form assertion the occurrence signed as attester, is read only while `edition2::door::earlier_form_doors_shut()` is false.
