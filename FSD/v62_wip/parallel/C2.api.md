# C2 fixture API: `test_ceremony_v2` (genesis bundle/2 test ceremony + Engine boot)

Status: PUBLISHED FIRST (before implementation). Every signature below is what C2 implements; if one changes, this header says so.

Changes since first publish (aligned to C1.api.md):
- `install_ceremony_v2` offers rows + voices in ONE list to C1's `put_genesis_bundle(dir, statements, anchor)`, after `edition2::genesis::add_test_attestation_root(mock root)`; it no longer calls `put_statement` for rows. Success is read back from `genesis_in_force` (so a re-install is Ok).
- Added `mock_attestation_root_der() -> Vec<u8>`. `attestation_roots()` (a store holding ONLY the mock root) is for calling Verify's reader directly; the door uses C1's own `genesis::attestation_roots()`.
- ADDED (team-lead ask, for E3's I429 flip): `recover_v2(prev, holder_seed)`, `TestCeremonyV2::holder_recovery_key(i)`, fields `HolderV2::{holder_seed, recovery_seed}`, `TestCeremonyV2::{extra_rows, recovered}`, consts `NEXT_RECOVERY_SEED_OFFSET = 60`, `RECOVERED_SEED_OFFSET = 40`. `later_v2` now carries prev's parties as prev seats them (a recovered holder keeps its re-seated key) and signs each voice under the holder's identity with its current key.
- ADDED (CC 4.2.6 witnesses): `recover_v2_with(prev, holder_seed, recovery_signer_seed, new_key_seed, next_recovery_seed)`, `recommit_v2(prev, holder_seed, recovery_seed, signers)`, consts `SECOND_RECOVERED_SEED_OFFSET = 80`, `SECOND_NEXT_RECOVERY_SEED_OFFSET = 70`. `recover_v2` now also does a SECOND recovery (key n+80, commits n+70); a third panics.
- A fresh bundle is asserted at `t0_ms + DAY_MS / 2`; a later one `LATER_STEP_MS` (60 s) after its predecessor.

Module path: `crate::federation::edition2::fixture_genesis` (file `src/federation/edition2/fixture_genesis.rs`), gated `#[cfg(any(test, feature = "test-anchor"))]`.
Integration tests (`tests/*.rs`) reach it as `ciris_persist::federation::edition2::fixture_genesis` and need `required-features = [.., "test-anchor"]`.

## The ceremony (pure, no I/O)

```rust
use ciris_crypto::composite::CompositeSigningKey;
use ciris_verify_core::cde::Value;
use ciris_verify_core::edition2::Digest32;
use ciris_verify_core::edition2::genesis::Anchor;
use ciris_verify_core::trust_anchor_store::TrustAnchorStore;

/// Holder seeds of the standard ceremony (Verify's vector keys A, B, C).
pub const HOLDER_SEEDS: [u8; 3] = [1, 2, 3];
/// Serve-node (seat) seeds of the standard ceremony (Verify's S1, S2).
pub const SERVE_NODE_SEEDS: [u8; 2] = [11, 12];
/// Holder seeds a custody chain exists for: a spec's holders must be among these.
pub const HOLDER_SEED_RANGE: core::ops::RangeInclusive<u8> = 1..=7;
/// `family_key_id` of the standard ceremony.
pub const FAMILY_KEY_ID: &str = "humanity-accord";
pub const DAY_MS: u64 = 86_400_000;
pub const YEAR_MS: u64 = 31_536_000_000;
pub const LATER_STEP_MS: u64 = 60_000;
pub const RECOVERY_SEED_OFFSET: u8 = 50;      // first recovery key: holder n -> key n+50
pub const RECOVERED_SEED_OFFSET: u8 = 40;     // after recover_v2, holder n signs with key n+40
pub const NEXT_RECOVERY_SEED_OFFSET: u8 = 60; // the recovery key recover_v2 commits next: n+60
pub const SECOND_RECOVERED_SEED_OFFSET: u8 = 80;      // after a second recovery: key n+80
pub const SECOND_NEXT_RECOVERY_SEED_OFFSET: u8 = 70;  // ...committing recovery key n+70

/// Composite test key n: ML-DSA-65 seed [n;32], Ed25519 seed [n+100;32]
/// (the door fixtures' `key(n)`, Verify's vector rule).
pub fn test_key(seed: u8) -> CompositeSigningKey;
/// A holder's recovery key: test_key(seed + 50) (Verify's REC rule).
pub fn recovery_key(holder_seed: u8) -> CompositeSigningKey;
pub fn kid_of(seed: u8) -> Digest32;            // thumbprint(test_key(seed))
pub fn identity_ref_of(seed: u8) -> String;     // identity_ref(&kid_of(seed))

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct CeremonySpec {
    pub holders: Vec<u8>,        // seeds, each in HOLDER_SEED_RANGE
    pub serve_nodes: Vec<u8>,    // seeds, disjoint from holders, not 51..=57
    pub t0_ms: u64,              // the records' instant; bundle asserted_at = t0_ms + DAY_MS / 2
    pub family_key_id: String,
}
impl CeremonySpec {
    /// HOLDER_SEEDS, SERVE_NODE_SEEDS, FAMILY_KEY_ID, t0 = (today's UTC midnight) - 1 day.
    pub fn standard() -> Self;
    /// standard() with a fixed t0 (deterministic bytes; seat records end t0 + YEAR_MS).
    pub fn at(t0_ms: u64) -> Self;
}

/// A named row: the statement bytes and the row id the bundle cites.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct NamedRow { pub row_id: Digest32, pub statement: Vec<u8> }

#[derive(Clone, Debug)]
pub struct HolderV2 {
    pub seed: u8,              // the key it signs with NOW (holder_seed, or holder_seed+40 after a recovery)
    pub holder_seed: u8,       // names the holder: identity_ref == identity_ref_of(holder_seed), for good
    pub recovery_seed: u8,     // the key its commitment commits to (holder_seed+50, then +60)
    pub kid: Digest32,
    pub identity_ref: String,
    /// key:record, identity_type {accord_holder}, attestation_evidence
    /// {hardware_class YubiKey_5_FIPS, pq_custody removable_offline, chain}.
    pub record: NamedRow,
    pub recovery_commitment: Digest32,
}

#[derive(Clone, Debug)]
pub struct SeatV2 {
    pub seed: u8,
    pub kid: Digest32,
    pub identity_ref: String,
    /// key:record, identity_type {node}, valid_until = t0 + YEAR_MS.
    pub record: NamedRow,
    /// identity:occurrence binding (transport_destination + both X-Wing keys, cites the record).
    pub binding: NamedRow,
    pub transit_xwing_pubkey: [u8; 1216],
    pub onion_hop_xwing_pubkey: [u8; 1216],
}

#[derive(Clone, Debug)]
pub struct TestCeremonyV2 {
    pub spec: CeremonySpec,
    pub version: u64,                 // 1 for ceremony_v2; prev+1 for later_v2
    pub prev: Option<Digest32>,
    pub asserted_at_ms: u64,
    pub holders: Vec<HolderV2>,       // spec order
    pub seats: Vec<SeatV2>,           // spec order
    pub extra_rows: Vec<NamedRow>,    // further named rows: a recovery's recovery-key record
    pub recovered: Option<String>,    // the identity_ref a recovery bundle recovers
    pub payload: Value,               // the bundle payload (closed CC map)
    pub voices: Vec<Vec<u8>>,         // one ceg-genesis-bundle/2 statement per signer
    pub object_id: Digest32,
}
impl TestCeremonyV2 {
    /// Every named row, by row id (Verify's GenesisInput.rows shape).
    pub fn rows(&self) -> std::collections::BTreeMap<Digest32, Vec<u8>>;
    /// The named rows in put order: holder records, seat records, then bindings.
    pub fn rows_in_put_order(&self) -> Vec<&NamedRow>;
    /// Anchor::Thumbprints(holder kids).
    pub fn anchor(&self) -> Anchor;
    pub fn holder_kids(&self) -> std::collections::BTreeSet<Digest32>;
    pub fn holder_identity_refs(&self) -> Vec<String>;      // spec order
    pub fn serve_node_identity_refs(&self) -> Vec<String>;  // spec order
    /// Replaces `canonical_genesis_bundle().serve_nodes[i].record.key_id`.
    pub fn serve_node_identity_ref(&self, i: usize) -> &str;
    /// Replaces `canonical_genesis_bundle().holders[i].record.key_id`.
    pub fn holder_identity_ref(&self, i: usize) -> &str;
    pub fn holder_key(&self, i: usize) -> CompositeSigningKey;
    pub fn serve_node_key(&self, i: usize) -> CompositeSigningKey;
    /// Holder i's committed recovery key: test_key(holders[i].recovery_seed).
    pub fn holder_recovery_key(&self, i: usize) -> CompositeSigningKey;
}

/// Verify's MOCK YubiKey PIV attestation root (DER).
pub fn mock_attestation_root_der() -> Vec<u8>;
/// A store holding only the MOCK root (for calling Verify's reader directly).
pub fn attestation_roots() -> TrustAnchorStore;

/// Mint a fresh genesis (version 1, no prev), signed by every holder.
/// Panics on a bad spec (seed outside HOLDER_SEED_RANGE, overlap): it is a fixture.
pub fn ceremony_v2(spec: &CeremonySpec) -> TestCeremonyV2;

/// Mint a later bundle over `prev`: `holders` / `serve_nodes` are the new
/// sets (seeds), `signers` the holder seeds whose voices it carries (judged by
/// the reader against prev's holders: strict majority + each added holder).
/// Records for new seeds are minted at prev's t0; asserted_at = prev's + LATER_STEP_MS.
pub fn later_v2(prev: &TestCeremonyV2, holders: &[u8], serve_nodes: &[u8], signers: &[u8]) -> TestCeremonyV2;

/// A RECOVERY over `prev` (CC 2.6.1.11, CC 4.2.6; RULINGS "A recovery is a
/// later bundle signed by the recovery key alone, changing only that seat"):
/// ONE voice, iss = the holder's identity_ref, kid = its committed recovery
/// key; names the recovery key's record (extra_rows) and the holder's new
/// record (key holder_seed+40, own custody chain); commits the next recovery
/// key (holder_seed+60). Other holders, seats, charter: as prev.
/// version prev+1, asserted prev + LATER_STEP_MS; new records 1 s earlier.
/// Panics: holder_seed not in prev, or already recovered (one recovery per holder).
/// Install with install_ceremony_v2(dir, &r) after prev is held.
pub fn recover_v2(prev: &TestCeremonyV2, holder_seed: u8) -> TestCeremonyV2;
// (a second recover_v2 of the same holder re-seats n+80 under rk n+60, committing n+70)

/// A recovery with every key chosen, for refusal witnesses: `recovery_signer_seed`
/// signs the lone statement (its record named), the holder is re-seated on
/// `new_key_seed` (must be n+40, n+80, or n+50 = the recovery key itself), and
/// `next_recovery_seed` is committed. The reader judges; the fixture does not.
pub fn recover_v2_with(prev: &TestCeremonyV2, holder_seed: u8, recovery_signer_seed: u8,
                       new_key_seed: u8, next_recovery_seed: u8) -> TestCeremonyV2;

/// A later (roster) bundle changing only holder_seed's commitment to
/// test_key(recovery_seed); `signers` (holder seeds) sign with current keys.
pub fn recommit_v2(prev: &TestCeremonyV2, holder_seed: u8, recovery_seed: u8, signers: &[u8]) -> TestCeremonyV2;

/// The standard ceremony (CeremonySpec::standard()), minted once per process.
pub fn bundle_v2() -> &'static TestCeremonyV2;
```

## Installing (through the real door)

```rust
/// What an install placed.
#[derive(Clone, Debug)]
pub struct InstalledV2 {
    pub object_id: Digest32,
    pub version: u64,
}

/// add_test_attestation_root(mock root); then C1's door
/// put_genesis_bundle(dir, rows-in-put-order ++ voices, Some(&c.anchor())).
/// Ok iff genesis_in_force(dir).valid holds c.object_id afterwards
/// (idempotent). Error: the door's refusal, unchanged.
/// Outside cfg(test), under test-anchor, the door trusts the mock root only
/// while `ciris_verify_core::test_anchor::test_anchor_active()` (C1's rule).
pub async fn install_ceremony_v2<F>(dir: &F, c: &TestCeremonyV2) -> Result<InstalledV2, crate::federation::Error>
where F: crate::federation::FederationDirectory + ?Sized;

/// install_ceremony_v2(dir, bundle_v2()).
/// Replaces: `seed_genesis_accord_holders` + `seed_family_and_canonical`,
/// `seed_accord_family`, `seed_canonical_servers`, `seed_delegation_plane`,
/// `seed_canonical_community_from`, `install_test_ceremony_outputs*`.
pub async fn install_v2<F>(dir: &F) -> Result<InstalledV2, crate::federation::Error>
where F: crate::federation::FederationDirectory + ?Sized;

/// install_v2 on an Engine's directory.
#[cfg(any(feature = "sqlite", feature = "postgres"))]
pub async fn install_v2_engine(engine: &crate::Engine) -> Result<InstalledV2, crate::federation::Error>;
```

## Engine boot

- Production (every build): `Engine::with_signer`, `with_signer_on_host`, `with_signer_arcs`, `with_hardware_signer`, `with_hardware_signer_hybrid` and `with_signer_pre_genesis` boot **pre-genesis**: no baked JSON genesis is seeded, nothing is rooted until a bundle/2 arrives at the import door. `from_shared*` never seeded and still does not. `build_backend` loses its `seed_genesis` flag.
- Lib unit tests (`cfg(test)` only): `with_signer`, `with_signer_on_host`, `with_signer_arcs`, `with_hardware_signer`, `with_hardware_signer_hybrid` call `install_v2` after boot, so a test Engine holds `bundle_v2()` with no call-site edit. A failed install panics with `test_ceremony_v2 install: <error>`. `with_signer_pre_genesis` NEVER installs: it is the test constructor for "a fresh node".
- Integration tests and `test-anchor` hosts (no `cfg(test)`):
  ```rust
  #[cfg(any(test, feature = "test-anchor"))]
  impl Engine {
      /// with_signer, then install_v2 (idempotent under cfg(test)).
      pub async fn with_signer_test_genesis(signer: Arc<LocalSigner>, dsn: &str) -> Result<Engine, EngineError>;
  }
  ```
  `EngineError::GenesisSeed(String)` carries an install failure here.
  **Integration tests must set `CIRIS_TESTING_MODE=true`** (C1: outside `cfg(test)` the MOCK root is registered only while `test_anchor_active()`), else the install fails `genesis_holder_custody`.
