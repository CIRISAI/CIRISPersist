## The door

```rust
/// One statement list: bundle voices (`ceg-genesis-bundle/2` object
/// statements, any number of objects: a whole lineage may travel) AND the
/// row statements they name (key records, seat bindings, a recovery key's
/// record), in any order. Held rows need not be resent.
/// `anchor`: the reader's anchor for a FIRST bundle not already held
/// (CC 5.3.4). `None` roots nothing new (`genesis_bundle_not_anchored`).
/// Held first bundles are re-read under their own object id.
pub async fn put_genesis_bundle<F>(
    dir: &F,
    statements: &[Vec<u8>],
    anchor: Option<&Anchor>,
) -> Result<GenesisAdmission, Error>
where F: crate::federation::FederationDirectory + ?Sized;

#[derive(Clone, Debug)]
pub struct GenesisAdmission {
    /// Each offered object Verify read Valid, in lineage order; its named
    /// rows and its voices are now held.
    pub placed: Vec<GenesisPlacement>,
    /// Each offered object that is not Valid (nothing of it stored).
    pub not_placed: Vec<NotPlaced>,
    /// Offered statements (by index) that are neither a bundle voice nor a
    /// row: each refused on its own, the others stand.
    pub unreadable: Vec<usize>,
    /// The re-derived state after the store.
    pub in_force: GenesisInForce,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct NotPlaced {
    pub object_id: Digest32,
    /// Verify's token: `genesis_bundle_malformed`, `genesis_bundle_count_unmet`,
    /// `genesis_bundle_not_anchored`, `genesis_bundle_prev_not_valid`,
    /// `genesis_bundle_row_unplaced`, `genesis_bundle_row_invalid`,
    /// `genesis_holder_custody`, or `genesis_bundle_waiting`.
    pub token: &'static str,
    /// Verify's reason / detail (`Malformed::reason()`, `Inconclusive::detail()`),
    /// or the waited-on row / prev ids for a Waiting bundle.
    pub detail: Option<String>,
    /// True for Waiting (retryable: a named row or the prev not held).
    pub waiting: bool,
}
```

Errors (`Err`) — only when NO offered object was placed:
- `earlier_form_object` for any JSON / non-COSE statement (bundle/1 included);
- `genesis_bundle_malformed` when no `ceg-genesis-bundle/2` statement is offered,
  and for an Invalid bundle (message carries Verify's reason);
- `Error::AttesterKeyUnknown` (retryable `federation_attester_key_unknown`,
  plane `edition2`, naming `ceg-genesis-bundle/2:<row or prev hex>`) for Waiting;
- the Inconclusive tokens above as `Error::MalformedRow` (they conclude
  nothing; never a finding against the bundle);
- storage errors.

## The held state (re-derived from the store every call; cached by content hash)

```rust
#[derive(Clone, Debug, Default)]
pub struct GenesisInForce {
    /// Every held bundle Verify reads Valid, lineage order.
    pub valid: Vec<GenesisPlacement>,
    /// `follow_to_head`'s head when there is no fork.
    pub head: Option<GenesisPlacement>,
    /// Every fork (`find_forks`); non-empty means `head` is None.
    pub forks: Vec<Fork>,
    /// `tips_in_common`: None on a genesis fork or with nothing held.
    pub common: Option<TipsInCommon>,
    /// The Valid lineage as served: each bundle's named rows then its voices.
    pub statements: Vec<Vec<u8>>,
}
impl GenesisInForce {
    pub fn is_held(&self) -> bool;                       // a Valid root is held
    pub fn family_key_id(&self) -> Option<&str>;         // the accord's name
    pub fn tips(&self) -> Vec<&GenesisPlacement>;
    pub fn holders(&self) -> &[PlacedHolder];            // common to every tip
    pub fn seats(&self) -> &[PlacedSeat];                // common to every tip
    pub fn seat(&self, identity_ref: &str) -> Option<&PlacedSeat>;
    pub fn is_canonical(&self, identity_ref: &str) -> bool; // ruling C
    pub fn bundle_seats(&self) -> super::liveness::BundleSeats; // holders+seats (iref,kid)
    pub fn halt_roster(&self, accord_root: &str) -> Option<super::halt::HaltRoster>;
}

pub async fn genesis_in_force<F>(dir: &F) -> Result<GenesisInForce, Error>;

pub async fn bundles_in_force<F>(dir: &F) -> Result<Vec<GenesisPlacement>, Error>;

pub async fn is_canonical_by_bundle<F>(dir: &F, identity_ref: &str) -> Result<bool, Error>;
```

## The halt door

`edition2::halt::roster_in_force(dir, accord_root) -> Result<Option<HaltRoster>, Error>`
keeps its signature; it now returns the roster of the bundle in force when its
`family_key_id == accord_root` (holders common to every tip, each at its placed
key; bundle = head, else the first tip; `halt_fuse_secs` = the head's charter,
or the tips' when they agree). No bundle held / genesis fork / other accord:
`None`, and the halt WAITS.

## Pure core (for fixtures that want no store)

```rust
pub struct LineageInput<'a> {
    pub held: &'a [Vec<u8>],     // held voices: first bundles rooted by own object id
    pub offered: &'a [Vec<u8>],  // offered voices: first bundles rooted by `anchor`
    pub rows: &'a BTreeMap<Digest32, Vec<u8>>,
    pub anchor: Option<&'a Anchor>,
    pub attestation_roots: &'a TrustAnchorStore,
}
pub struct LineageObject {
    pub reading: BundleReading,   // Verify's, top-level refusals folded into `refused`
    pub kept: Vec<Vec<u8>>,       // voices no step refused (what the store keeps)
    pub named: Vec<Digest32>,     // rows the payload names (refs minus prev)
    pub prev: Option<Digest32>,
    pub held: bool,
    pub offered: bool,
}
pub struct LineageReading {
    pub objects: Vec<LineageObject>, // read order: roots, then each after its prev, then orphans
    pub unreadable: Vec<usize>,      // statements (index into held ++ offered) naming no object
}
pub fn read_lineage(input: &LineageInput<'_>) -> LineageReading;
```
