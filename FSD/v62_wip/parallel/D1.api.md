# D1.api.md: the v62 PyO3 surface D1 adds (for D3's Python tests)

Status: CHANGED (rev 5: new `amendment_standings_json(agent)`; rev 4: `plane` may be `"pending"` (T1's `StatementOutcome::Pending`: the voice is kept, but there is no typed row yet because the group protocol is short); rev 3: a Python Engine boots pre-genesis, with no bundle/1 seed, so a fresh `Engine(...)` holds no genesis until a bundle/2 is imported; rev 2): `bundles_in_force_json` takes NO `pin` (C1 removed it from `bundles_in_force`) and returns more members per tip; `earlier_form_doors_shut` is re-exported from the `ciris_persist` package. Nothing is built: every line is BELIEVED.

All four are methods of `ciris_persist.Engine` (PyO3 `PyEngine`). The GIL is released for the store call. Errors go through `federation_err_to_py`, so every refusal keeps the Python type and message shape of the existing arms:

- an edition-2 door refusal is `ValueError("federation_malformed_row: <plane>: <reason>")`, where `<reason>` starts with the token (`earlier_form_object`, `row_id_mismatch`, `row_ref_edition_1`, `edition2_statement_invalid`, `kid_not_of_iss`, `key_record_out_of_window`, ...); the edition-2 plane is `edition2` (the `door::PLANE` constant);
- a statement whose signer's key record is not held is `ValueError("federation_attester_key_unknown")`, retryable;
- the attestation gates raise exactly what `put_attestation` raises for the same row.

## put_edition2_statement

```python
def put_edition2_statement(self, statement: bytes, offered_row_id: str | None = None) -> str: ...
```

- Wraps `Engine::put_edition2_statement` (tier `federation`).
- `statement`: one `COSE_Sign1` (tag 18) statement, as received.
- `offered_row_id`: 64 hex chars (case-insensitive on input), or None. A malformed hex string is `ValueError("offered_row_id: ...")`, never a door call.
- Returns JSON: `{"plane": "key_plane" | "voice" | "row" | "pending", "row_id": "<64 lowercase hex>", "new": bool}`.
- A JSON string or JSON bytes at this door is refused `federation_malformed_row: edition2: earlier_form_object` (the door's own check; this does NOT depend on the switch).

## apply_replicated_statement

```python
def apply_replicated_statement(self, statement: bytes, offered_row_id: str) -> str: ...
```

- Wraps `edition2::ingest::apply_replicated_statement` (there is no Engine method).
- `offered_row_id` is required (the id the peer offered it as).
- Returns JSON:
  - `{"outcome": "admitted", "plane": ..., "row_id": ..., "new": true, "advances_cursor": true}`
  - `{"outcome": "unchanged", "plane": ..., "row_id": ..., "new": false, "advances_cursor": true}`
  - `{"outcome": "refused", "reason": "store_conflict", "advances_cursor": true}` (`reason` is `AttestationRefusalReason`'s snake_case token)
- A statement waiting on its signer's key is the retryable `ValueError("federation_attester_key_unknown")`; the caller must not advance its cursor.

## bundles_in_force_json

```python
def bundles_in_force_json(self) -> str: ...
```

- Wraps `edition2::genesis::bundles_in_force(dir)` (C1: Verify's `GenesisPlacement` per tip).
- Returns a JSON list (empty when no bundle is held), one entry per tip:
  `{"object_id": "<64 hex>", "version": int, "prev": "<64 hex>" | null, "asserted_at": <POSIX ms>, "family_key_id": str, "holders": ["urn:ietf:params:oauth:ckt:sha-256:..."], "serve_nodes": [...], "counted": [...]}`.
  `holders` is in roster order, `serve_nodes` in seat order, `counted` sorted.
- Two entries mean a fork: both tips are in force.

## edition2_statements_since

```python
def edition2_statements_since(self, cursor: str | None = None, limit: int = 1000) -> list[tuple[str, bytes]]: ...
```

- Wraps `FederationDirectory::edition2_statements_since`.
- Each item is `(cursor, statement_bytes)`: the statement as received, and the cursor to pass back to resume after it.
- A cursor is the opaque string `"<admitted_us>:<statement_id 64 hex>"`. Pass back the LAST item's cursor. A malformed cursor is `ValueError("cursor: ...")`.
- `limit` is clamped by the store to 1000 (`MAX_PAGE`).

## amendment_standings_json (rev 5)

```python
def amendment_standings_json(self, agent: str) -> str: ...
```

- Wraps P2c's `identity_amendment::amendment_standings_for(dir, agent)`, read at the time of the call (nothing is stored).
- Returns a JSON list: `[{"row_id": str, "standing": "in_force" | "held", "token": str | null, "reason": str | null, "detail": str | null}]`.
- `token` is `identity_amendment_unauthorized` or `amendment_digest_mismatch`. `reason` is the case, e.g. `response_not_held`, `response_not_approved`, `amendment_digest_differs_from_approved`.
- A held amendment starts counting once its approval lands; re-read to see it.
