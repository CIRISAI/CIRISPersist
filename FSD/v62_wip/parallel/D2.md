### `src/server/edition2.rs` (new)
An **opt-in** router. It is NOT merged into `server::router`, so no existing deployment grows a write surface. It mirrors the `secrets::router` composition.
- `router(Edition2State<F>)`:
  - `POST /v1/edition2/statements`: the body is one COSE statement. `?row_id=<64 hex>` routes to the replicated door; without it, the local door runs.
  - `GET /v1/edition2/bundles-in-force`: the JSON shape matches D1.
- `serve_router(..)`: `GET /v1/edition2/statements?after=<us>:<hex>&limit=N`, answered `{"statements":[{"cursor","statement":hex}],"next"}`.
  - **OFF by default (lead ruling 2026-11-18: no serving without an audience filter).** `Edition2State::new(dir)` sets `serve_listing_unfiltered: false`, and the GET answers 403 `serve_listing_disabled` and serves nothing. Only a test sets the flag.
  - I read cut B's tree (`/home/emoore/CIRISPersist-w62cutb` @ d5b39133). Its serving path does NOT filter by audience: `edition2_statements_since` → `statements_since_{sqlite,pg}`, `edition2_statement_ids_since` behind `list_wire_hashes_since(STATEMENT_KIND)`, and `lookup_by_id` all read `ceg_statements` without audience or withholding. So there is no filtered path to wire the route through yet.
- `F: FederationDirectory + ?Sized`, so `Arc<dyn FederationDirectory>` composes.
- Limits: a 1 MiB body cap (`MAX_STATEMENT_BODY_BYTES`, 413 above it); `DEFAULT_PAGE` 100; the store clamps to `MAX_PAGE`.
- Status codes:
  - 200: admitted, unchanged, or a replicated `refused` with its `reason`;
  - 400: a bad query;
  - 422: a terminal refusal, with `kind`, `plane` and `reason`;
  - 424: `federation_attester_key_unknown`, `retryable: true`;
  - 500: `Backend` or `Unsupported`. The detail is logged and not served.
- `trust_root_statements(dir)` (`pub(crate)`) returns C1's `genesis_statements`, hex-encoded, in the shape `{"statements":[…]}`.

Nothing on syn0 required that yet: Engine is the only caller, and it is never spawned. I read the bodies for `Rc`/`RefCell`/guards and found none, but the HeldKeys / Verify types were not checked for `Send`. If one is not Send, both the capsule (`BoxedFut`) and axum `Handler` fail.

3. **The digest pins** (see above). Also the I2487/I1322 from-disk scans: the classifier's first `=> None` must stay after all earlier-form arms (it does: the edition-2 group was moved to the end for this reason).
