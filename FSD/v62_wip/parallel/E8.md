- **NEW `test_support::e2bind`** (`cfg(sqlite|postgres)`): the builders the matrices share.
  - `Bind { author, identity, occurrence, device_class, asserted_at_ms, valid_until_ms, extra }`, with `new / with / until / payload / voice(signer, iss) / own_voice / author_voice / voices`.
    - The payload is O1's member set; keys go through `e2::kid`.

## Production gaps found (reported; O1 is fixing both in O1.patch)

1. **Expiry (FIXED by O1, witnesses I3037/I3042; I3327 depends on O1.patch and is expected green with it).** `occurrence_admit::plan_occurrence` projects the #446 route without regard to `valid_until`. Neither `list_transport_destinations_for` nor `fold_one_live_key` reads the occurrence window (read-checked). The door checks only `valid_until > asserted_at`, so a bind whose window has already passed lands and projects a route that stays live indefinitely. Possible fixes:
   - skip the projection when `valid_until <= now`;
   - or retire projected routes whose occurrence has lapsed;
   - or filter routes on read.
2. **X-Wing resolution (FIXED by O1, witnesses I3038/I3039; I3331 depends on O1.patch).** `transit_xwing_pubkey_for` / `transit_kex_pair_for` read only `list_signed_transport_destinations_for`, the earlier-form plane. An edition-2 bind's `transit_xwing_pubkey` is checked by `check_xwing_in_row` and kept in the statement, but `IdentityOccurrence` has no field for it and the projected route is local. So for a non-seat node the key is never resolvable. W1 covers seats only.

## Compile risks (could not confirm without building)

## Behaviour risks (believed green, but not certain by reading)

- **I3312.** Flipping the statement's last byte assumes it falls inside the COSE signature bstr, which is the last array member. Any Verify `Invalid` maps to the same token, so the risk is low.
- **I3322 / X-Wing non-bytes.** The token is P1d's `payloads::check` (`edition2_payload_invalid`). If an earlier gate refuses an unknown member under a different token, update the expected token.
