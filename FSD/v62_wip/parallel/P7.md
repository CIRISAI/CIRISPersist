## The ruling, as applied

- A trace (`trace:complete:v1`, SPLIT plane) carries ONE composite ML-DSA-65-Ed25519 signature, verified with Verify's `CompositePublicKey::verify` (ciris-crypto v23.3.0, read-checked: `verify(msg, sig) -> Result<(), CryptoError>`, 3373-byte sig, both halves over the LAMPS -19 representative).
- The key is resolved by the trace's kid (`signature_key_id`, an identity-ref) through the edition-2 key plane: `edition2::ingest::held_keys_for_kid` then `HeldKeys::liveness(kid, at)` (SelfOnly standing, what the gates read; same shape as P6's secrets door). Only `Live` admits.
- **The instant is the trace's SIGNED `completed_at`** (ms), as a statement is read at its own `asserted_at` (the door calls `keys.liveness(&row.kid, row.asserted_at_ms)`, edition2/ingest.rs l.519/680, read-checked). It is a shared verdict (traces replicate), so a node clock would give different nodes different answers. A revoke-all revocation is final at every instant; a bounded one lets earlier traces stand, exactly the key plane's rule. **Decision for the lead:** if you want node-now instead, change one line (`let at = …` in `verify_composite_trace_for_admission`).
- **Domain tag (decision for the lead):** the signed message is `TRACE_SIGNATURE_CONTEXT || canonical_bytes_for_trace(..)`, with `TRACE_SIGNATURE_CONTEXT = b"ciris-persist:trace:complete:v1"` (P6 precedent: `ciris-persist:secrets-request:v1`). It keeps a trace signature from reading as any other object the same composite key signs (CC 2.6.1.7 domain separation). To sign the bare canonical bytes instead, drop the two `extend_from_slice` lines in `trace_signature_message` and delete I3470.
- The earlier bound-hybrid form is refused by name (`earlier_form_object`) behind the one switch (`door::refuse_earlier_form`), before any key read. While the doors are open it runs the existing #225/#789 path unchanged, except for the new cross-form refusal below.

## Agent adoption note (exact wire)

The trace JSON keeps its shape (`CompleteTrace`, TRACE_WIRE_FORMAT §3). For a v62 node:

1. Build `canonical = canonical_bytes_for_trace(trace)`: unchanged. The field set dispatches by the signed `trace_schema_version` (2.7.0 / 2.7.9 / 3.0.0 / 2.7.legacy); a signed `run_kind` joins at the top level; the canonicalizer is RFC 8785 JCS for schema major ≥ 3, Python-compat `json.dumps(sort_keys, separators=(",",":"))` below.
2. `message = b"ciris-persist:trace:complete:v1" + canonical` (31 ASCII bytes, no separator, no length prefix).
3. `sig = composite_sign(message)`: CC 2.6.1.7 ML-DSA-65-Ed25519 composite (Verify `CompositeSigningKey::sign` / `SplitCompositeSigner::sign` / `assemble_composite`), i.e. `mldsaSig(3309) || ed25519Sig(64)` = 3373 bytes, both halves over `M' = "CompositeAlgorithmSignatures2025" || "COMPSIG-MLDSA65-Ed25519-SHA512" || 0x00 || SHA-512(message)`, ML-DSA with the label as its FIPS 204 context. Hand the composite signer `message`, never a hash of it.
4. Set on the trace:
   - `"signature"`: base64 of the 3373 bytes (standard alphabet preferred; URL-safe, padded or not, is also accepted);
   - `"signature_key_id"`: the key's identity-ref `urn:ietf:params:oauth:ckt:sha-256:<base64url thumbprint>` (the kid its `key:record` names);
   - **omit** `signature_ml_dsa_65`, `pubkey_ml_dsa_65` and `pqc_key_id`. Any one of them present makes the trace the earlier form.
5. The node must hold a valid `key:record` of that key (an `agent` key; `valid_until` per the end rule) whose window covers the trace's `completed_at`, with no revocation in effect at it.

Refusals (Python `ValueError`, `args[0]` the token; lens HTTP 4xx):

| token | when |
|---|---|
| `verify_unknown_key` | no valid `key:record` of the kid is held (retryable: the record may not have arrived) |
| `verify_signer_not_live` (NEW) | the key is revoked, no record covers `completed_at`, or a record waits on a deeper key; the detail starts `revoked:` / `not_covered:` / `waiting:` |
| `verify_invalid_signature` | `signature` not base64, or not 3373 bytes |
| `verify_signature_mismatch` | does not verify under the kid's key: a trace signed by a key not of its kid, or altered after signing |
| `earlier_form_object` | `ValueError(("earlier_form_object", detail))`: a bound-hybrid / classical-only trace once the earlier-form doors are shut |
| `earlier_form_signer_is_edition2` | (doors open) a bound-hybrid trace whose `signature_key_id` or `pqc_key_id` names an edition-2 key: a composite's components are never standalone signers |
